# My project

Maze Escape – README
Overview
Maze Escape is a first-person 3D maze game developed in Unity. The objective of the game is to collect coins and crystals scattered throughout the maze to earn enough points before reaching the goal area. Players must also avoid the lava zone, which continuously damages the player while they remain inside it.

How to Run the Application.

1.	Wait for the game to load.
2.	Use the keyboard controls listed below to navigate the maze.
3.	Collect coins and crystals to gain points.
4.	Reach a minimum score of 170 points.
5.	Enter the goal area to clear the level.

Controls
Key	Action
W	Move Forward
A	Move Left
S	Move Backward
D	Move Right
Arrow Keys	Alternative Movement Controls
E	Interact / Collect Items / Open Doors
Mouse	Look Around




Gameplay Information
Collectibles
•	Coin = 10 Points
•	Crystal = 30 Points
Objective
•	Reach at least 170 points.
•	Locate and enter the goal area to clear the level.
Health System
•	The player starts with 100 Health.
•	Standing in lava causes damage over time.
•	If health reaches 0, the player dies and the game resets.
UI Elements
•	Current Score
•	Points Left to Reach Target Score
•	Collectibles Remaining
•	Player Health
•	Gameplay Instructions
•	Status Messages

Known Limitations / Bugs
•	Collectible sound effects may overlap when multiple items are collected quickly.
•	The game currently contains only one level.
•	There is no pause menu implemented.
•	The player is reset to the starting position after death or level completion.
•	The game is designed for keyboard and mouse controls only.

Puzzle / Game Solution
1.	Explore the maze and collect coins and crystals.
2.	Keep track of the score displayed on screen.
3.	Avoid staying in the lava zone for too long.
4.	Continue collecting items until at least 170 points are obtained.
5.	Locate the goal area.
6.	Enter the goal area to complete the level.
